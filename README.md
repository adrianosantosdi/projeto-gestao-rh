# 🚀 CoreRH - Gestão Inteligente de Capital Humano

![TailwindCSS](https://img.shields.io/badge/tailwindcss-%2338B2AC.svg?style=for-the-badge&logo=tailwind-css&logoColor=white)

**CoreRH** é um ecossistema de gestão de Recursos Humanos desenvolvido para oferecer uma experiência visual de alto nível (Ultra Dark Mode) e uma arquitetura sólida para o gerenciamento de ativos empresariais.

> "Transformando dados brutos em inteligência operacional."

---

## 💎 Diferenciais do Projeto

* **Dashboard Executivo:** Métricas em tempo real sobre colaboradores, empresas e documentos.
* **Arquitetura MTV:** Implementação limpa seguindo os padrões oficiais do Django.
* **UI/UX Premium:** Interface construída com Tailwind CSS, focada em produtividade e baixa fadiga visual.
* **Sidebar Dinâmica:** Navegação inteligente com detecção automática de rota ativa.
* **Gestão de Documentos:** Repositório centralizado para protocolos e arquivos de funcionários.



---

## 🛠️ Tecnologias Utilizadas

* **Backend:** Python 3.x & Django Framework.
* **Frontend:** Tailwind CSS (via CDN/JIT) para estilização ultra-rápida.
* **Banco de Dados:** SQLite (Desenvolvimento).
* **Ícones:** HeroIcons (SVG).
* **Fontes:** Inter & JetBrains Mono (Google Fonts).

---

## 📂 Estrutura de Módulos

O sistema é dividido em blocos lógicos para facilitar a escalabilidade:

1.  **Empresas:** Cadastro de unidades e matrizes.
2.  **Departamentos:** Organização setorial da estrutura empresarial.
3.  **Funcionários:** Ficha completa, avatares e vinculação setorial.
4.  **Horas Extras:** Lançamento, histórico e cálculos agregados no banco de dados.
5.  **Documentação:** Upload e controle de arquivos por categoria.
